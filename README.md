# mcp-memory-stack
Provides memory for AI via containerized MCP servers

[Documentation is in the WiKi](https://github.com/ai-memory-project-2026/mcp-memory-stack/wiki/Home)


## Summary ##
This stack of Docker containers provides external memory capabilities to a LLM via MCP.
Access is secured via OAuth.


### Goals
This project is mostly for documenting what works for my personal setup.

I've tried different approaches to solve the problem of continuity with current AI implimentations.
Keeping data on hardware I control seemed the most logical next step.



### What to expect
I'll extent the "memory" part with tools I often use - like an MCP server for image generation.
This is not a product of some kind, I write things up when I find time to do so.
